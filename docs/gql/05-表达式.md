# 表达式

表达式用在 `WHERE`、`RETURN`、`ORDER BY`、`SET` 的右值，以及模式里的属性值。

## 运算

优先级从高到低：括号和原子、一元负号、`*` `/`、`+` `-`、比较和 `IN` / `IS NULL`、`NOT`、`AND`、`OR`。

比较符：`=`、`<>`、`<`、`<=`、`>`、`>=`。一次比较两个值，不能写 `1 < a.id < 3`。

```text
WHERE b.id = 2 AND NOT a.name IS NULL
WHERE e.ratio >= 0.2 OR b.id IN (2, 3, 4)
WHERE a.name IS NOT NULL
```

`IS NULL`、`IS NOT NULL` 判断空。`NULL` 参与 `=` 时对不上，要用 `IS NULL`。

数字可以相加、相减、相乘、相除。整数运算溢出会报错。没有取模、乘方。

字符串没有「开头是」「包含」这类运算符，只用 `=`。

## 属性和变量

`a.name` 是变量 `a` 的属性 `name`。`a.id` 是点的编号，不是属性列。`e.rank` 是边的 `rank`。

`RETURN a` 返回整个点，`RETURN e` 返回整条边。形状见 [插入](03-插入.md)。

## 函数

名字不区分大小写。参数个数必须对上。

| 函数 | 作用 |
|---|---|
| `id(a)` | 点的编号。边上没有 `id` |
| `labels(a)` | 这一个类型名，字符串 |
| `properties(a)` | 属性映射。没有属性时是空映射 |
| `startNode(e)` | 边的出端编号 |
| `endNode(e)` | 边的入端编号 |
| `coalesce(a.name, 'none')` | 从左到右，取第一个非空值 |
| `count(*)` | 行数。只能写在 `RETURN` |
| `sum(e.ratio)` | 求和。只能写在 `RETURN` |

`labels` 和 `type` 都返回当前实现中的类型名。虽然 `type` 是关键字，它在函数调用位置仍然可以写成 `type(e)`。

`size`、`length` 接受列表、映射和字符串。列表和映射属性类型仍在后续阶段实现。

聚合不能和普通列写在一起，不能再加 `DISTINCT`，也不能再 `ORDER BY`：

```text
MATCH (a:Company {id:1})-[e:holder]->(b) RETURN count(*) AS n, sum(e.ratio) AS total
```

没有匹配行时，`count(*)` 是 `0`，`sum` 是空。

`WHERE` 里写 `count` 或 `sum` 会报「聚合只能写在 RETURN」。

## 标准里还有

`CASE`、字符串函数、日期函数、`avg`、`min`、`max`、`collect`，以及 `EXISTS { ... }` 这种子查询。这里都没有。
