# 和标准 GQL 相比

对照的是 ISO/IEC 39075:2024（GQL）。目标是做标准的**超集**：标准写法都能解析，含义和标准一致；层岩自己的写法作为扩展保留，不改变标准写法的含义。

网络 `execute` 请求执行一条语句；Studio 编辑器和 Python `file` 命令可以用分号拆分多条语句顺序执行，但不组成跨语句事务。

## 已经按标准支持

- **词法**：`//`、`--`、`/* */` 注释；Unicode 标识符；反引号名字；单双引号字符串和转义；`1e8`、`0x1F`、`1_000`、`1.5d`。
- **模式**：多段路径、逗号分隔的多个模式、`OPTIONAL MATCH`、`OPTIONAL { ... }`；点和边上的完整标签表达式（`&`、`|`、`!`、`%`、括号，`:` 或 `IS`）；点和边内联 `WHERE`；完整和缩写的边写法；量词 `*`、`+`、`?`、`{n}`、`{m,}`、`{,n}`、`{m,n}`；路径并集 `|` / `|+|`；量化路径模式 `((a)-[e]->(b) WHERE ...){m,n}`；`DIFFERENT EDGES` / `REPEATABLE ELEMENTS`。
- **路径**：每个路径模式自己的路径变量和前缀；`ALL`、`ANY [k]`、`ANY SHORTEST`、`ALL SHORTEST`、`SHORTEST k`、`SHORTEST k GROUPS`；`WALK` / `TRAIL` / `SIMPLE` / `ACYCLIC`；`PATH` / `PATHS`。
- **管道语句**：`MATCH`、`FILTER`、`LET`（多个绑定）、`FOR ... WITH ORDINALITY / OFFSET`、`ORDER BY` / `OFFSET`（`SKIP`）/ `LIMIT`、`CALL`（命名过程、内联过程、`OPTIONAL CALL`），可以写在开头或中间。
- **结果**：`RETURN [DISTINCT|ALL] ... GROUP BY ...`、`RETURN *`、`RETURN NO BINDINGS`、`FINISH`。
- **组合**：`UNION` / `EXCEPT` / `INTERSECT [ALL|DISTINCT]`、`OTHERWISE`、`NEXT [YIELD ...]`，右边可以是任意线性查询。
- **表达式**：三值逻辑，`OR` / `XOR` 同级；`IS [NOT] NULL / TRUE / FALSE / UNKNOWN / TYPED / LABELED / DIRECTED / SOURCE OF / DESTINATION OF`、`n:Label`；`SAME`、`ALL_DIFFERENT`、`PROPERTY_EXISTS`；`EXISTS { }`、`VALUE { }`；`CASE`、`CAST`、`NULLIF`、`COALESCE`、`LET ... IN ... END`、`LIST[...]`、`RECORD {...}`；字符串、数学、路径函数（见表达式一页）。
- **写入**：`INSERT`（多个元素）、`SET`（属性、整体、标签）、`REMOVE`（属性、标签）、`[DETACH|NODETACH] DELETE`，任意顺序组合，之后可以 `RETURN` / `FINISH`。
- **图**：`USE g 查询`（只对这一条换图）、`SESSION SET [PROPERTY] GRAPH g`、`CREATE [PROPERTY] GRAPH [IF NOT EXISTS] g { 类型 } | LIKE g2 | ANY`、属性默认可空和 `NOT NULL`。

## 标准里有、这里还没有

按影响排序。这些写法会给出明确的报错，不会被当成别的意思执行。

**存储模型**

- 一个点或边有多个标签。层岩一个元素只有一个类型；标签表达式可以用来选择，但 `SET n:另一个标签`、`(:A&B)` 建类型、插入多标签点会报错。
- 跨语句事务 `START TRANSACTION` / `COMMIT` / `ROLLBACK`。每条语句单独提交。
- 属性类型 `DATE`、`TIME`、`LOCAL DATETIME`、`DURATION`、`LIST`、`RECORD`、`BYTES`、`DECIMAL`、定宽整数和 `FLOAT32`，以及对应的字面量和函数（`CURRENT_DATE` 等）。现有类型：`BOOL`、`INT64`、`DOUBLE`、`STRING`、`DATETIME`。
- 点的编号固定叫 `id`，是保留属性名；标准里元素的身份由 `ELEMENT_ID()` 给出，不占属性名。

**目录和会话**

- 单独命名的图类型 `CREATE GRAPH TYPE`、`TYPED 图类型名`、`AS COPY OF`、`CREATE OR REPLACE`、`CREATE SCHEMA` 和目录路径。
- 边类型两端的点类型只做语法检查，插入时不校验。
- `SESSION SET SCHEMA / TIME ZONE / VALUE`、`SESSION RESET`、`SESSION CLOSE`。只支持 `SESSION SET GRAPH`。

**查询**

- `KEEP` 子句、可选特性 `SELECT` 语句、`NULLS FIRST / LAST`。
- 量化路径模式里有多条边；一个路径模式里有多段时使用路径变量、搜索前缀或量化路径。
- 写入之后继续查询（`SET ... MATCH ...`）；同一条语句里既改属性又级联删除。
- 子查询（`EXISTS` / `VALUE` / 内联 `CALL`）里写集合运算、`NEXT` 或写入。
- 枚举路径（非最短路）时跳数上界超过 32 或不写上界。
