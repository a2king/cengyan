# 通用图数据库改造路线图

## 已完成：契约、执行策略、批量导入与 Schema 注释

- 统一所有 Maven 模块到 `1.0.0`；
- 明确标准 GQL、层岩扩展和执行策略边界；
- 默认不再使用固定的 64 条边、64 个前沿节点、10 跳和 100 条路径作为默认预算；配置值 `0` 表示不限；
- 保留显式预算、超时和取消机制；
- 支持 Schema `COMMENT` 元数据、`bulkInsert` JSON 导入和参数化 Spark 导入；

## 下一阶段：通用模式查询

- 多段路径和多模式连接；
- `OPTIONAL MATCH`；
- 路径变量、路径值和路径函数；
- 多跳节点属性、边属性和路径过滤；
- 明确 `WALK`、`TRAIL`、`SIMPLE` 路径语义。

执行器层面的优化（谓词下推、扫描窗口、属性索引接入、轻量 EXPLAIN）与功能阶段并行推进，差距分析和计划见 [11-执行器优化差距-与Neo4j对照.md](11-执行器优化差距-与Neo4j对照.md)。

## 第三阶段：关系运算和表达式

- `WITH`、`UNION`、`INTERSECT`、`EXCEPT`；
- `GROUP BY`、`avg`、`min`、`max`、`collect`；
- `CASE`、字符串函数、日期函数；
- 列表、映射、记录值和子查询。

## 第四阶段：写入和事务

- `MERGE` / UPSERT；
- `REMOVE`、`DETACH DELETE`；
- 批量模式插入；
- 事务 API、默认值、约束和 Schema Migration。

## 第五阶段：分布式图能力

- 跨分片边；
- 跨分片读写和一致性；
- 分布式索引、最短路和聚合；
- 备份恢复、CDC、全文索引和向量索引。
