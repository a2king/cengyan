# 修改和删除

`SET` 和 `DELETE` 都从 `MATCH` 开始，先找出要动的行，再改。只支持一跳。箭头后面写 `{1,3}` 会报「修改和删除只支持一跳」。

匹配规则和 [查询](04-查询.md) 相同：类型、方向、`|`、不写类型，都可用。一条语句改完一起提交。失败时不会留下半截修改。

## SET

左值是 `变量.属性`，右值是表达式。

```text
MATCH (a:Company {id:1})-[e:holder]->(b {id:2}) SET e.ratio = 0.8, b.name = 'child'
MATCH (a:Company {id:1}) SET a.name = 'renamed'
```

`id` 不能被 `SET`。`rank` 也不是可以改的属性。属性名必须是这个类型上有的列。

边上写了多个类型时，每个类型都要有被赋值的那一列。不写边类型时，碰到没有这一列的边会报未知属性。

`WHERE` 可以加在 `SET` 前面：

```text
MATCH (a {id:1})-[e:holder]->(b) WHERE e.ratio < 0.3 SET e.ratio = 0.3
```

## DELETE

删除列出的变量。变量必须是模式里出现过的。

```text
MATCH (a {id:1})-[e:holder]->(b {id:2}) DELETE e
MATCH (a {id:3}) DELETE a
```

`DELETE e` 删边。`DELETE a` 删点。点上还有边时直接报错。要连边一起删，写成 `DETACH DELETE a`。`NODETACH DELETE` 和默认的 `DELETE` 一样，有边就失败。

可以在一条语句里只删边，或只删点。不写边的 `MATCH (a {id:3}) DELETE a` 用来删点。

`REMOVE a.note` 把可空属性写成空。`SET a = {name: 'x', note: NULL}` 按映射整体赋值。

一条 `INSERT` 可以写多个点和多条边，用逗号隔开。`DROP NODE TYPE` 和 `DROP REL TYPE` 会删掉这个类型和它的数据。`ALTER ... DROP 列` 把列标成不可见，`ALTER ... RENAME 列 TO 新名字` 只改目录里的名字。

## 还没有

`MERGE` 没有。没有跨多条语句的 `BEGIN` / `COMMIT`。一次请求里的多条语句按顺序执行，任何一条失败，后面的不再执行；每一条修改自己提交。
