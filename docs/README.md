## 约定

- 标准 GQL 子集、层岩扩展和执行策略分开描述；
- `COMMENT` 是 Schema 元数据扩展，不是普通解析阶段注释；
- `bulkInsert` 是 JSON 导入协议，不是 GQL 文本语句；
- 文档中的 `0` 预算表示不限，具体部署可以在 `cengyan.properties` 中设置正数；
- 网络 `execute` 一次执行一条语句，Studio 和 Python 文件执行器可以顺序发送多条语句。
